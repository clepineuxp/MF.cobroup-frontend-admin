# ADR-000 — Fundación de fase 1

- Angular 21 LTS, standalone, TypeScript estricto y SCSS.
- PWA activa desde el inicio; caché únicamente de shell.
- Tema claro inicial y selector claro/oscuro persistente.

- Iconos generados por Angular pendientes de reemplazo por identidad COBROUP aprobada antes de producción.
